┌──────────────────────────────────────────────────────────────────────┐
│                    STORAGE CALCULATIONS                               │
└──────────────────────────────────────────────────────────────────────┘

Example: 10km radius around San Francisco (37.7749, -122.4194)

Zoom 12:  4 x 4 tiles   =     16 tiles  (~640 KB)
Zoom 13:  8 x 8 tiles   =     64 tiles  (~2.5 MB)
Zoom 14: 16 x 16 tiles  =    256 tiles  (~10 MB)
Zoom 15: 32 x 32 tiles  =  1,024 tiles  (~40 MB)
Zoom 16: 64 x 64 tiles  =  4,096 tiles  (~160 MB)
                         ────────────────────────────
TOTAL (Zoom 12-16):      5,456 tiles    (~218 MB)

With all 3 sources (osm, carto_dark, satellite):
    218 MB x 3 = ~654 MB

Actual download for 10km, zoom 12-16:
    ~32,000 tiles ≈ 1.3 GB (with overlap & satellite imagery)

│                    QUICK COMMAND REFERENCE                            │
└──────────────────────────────────────────────────────────────────────┘

Download Tiles:
───────────────
npm run tiles:download -- --lat 37.7 --lon -122.4 --radius 10 --zoom 12-16

Start Tile Server:
──────────────────
npm run tiles:serve

Start GCS Offline:
──────────────────
npm run dev:offline

Test Tile Server:
─────────────────
Start-Process "http://localhost:8080/osm/10/163/395.png"

Check Tile Count:
─────────────────
Get-ChildItem -Path ./static/map/tiles -Recurse -File | Measure-Object

Calculate Storage:
──────────────────
(Get-ChildItem -Path ./static/map/tiles -Recurse -File | 
 Measure-Object -Property Length -Sum).Sum / 1GB

│                         URLS EXPLAINED                                │

Tile URL Template:
──────────────────
http://localhost:8080/{source}/{z}/{x}/{y}.{format}
│                 │   │        │   │   │    │
│                 │   │        │   │   │    └─ File format (png/jpg)
│                 │   │        │   │   └────── Y coordinate (row)
│                 │   │        │   └────────── X coordinate (column)
│                 │   │        └────────────── Zoom level (0-22)
│                 │   └─────────────────────── Tile source
│                 └─────────────────────────── Tile server port
└──────────────────────────────────────────── Protocol & host

Examples:
─────────
http://localhost:8080/osm/14/2621/6333.png
→ OpenStreetMap, zoom 14, tile (2621, 6333)

http://localhost:8080/satellite/16/10485/25334.jpg
→ Satellite imagery, zoom 16, tile (10485, 25334)

http://localhost:8080/carto_dark/12/655/1584.png
→ Dark mode, zoom 12, tile (655, 1584)
